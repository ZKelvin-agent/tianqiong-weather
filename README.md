# 天穹气象台 · 实时 3D 地球天气

在线地址：https://zkelvin-agent.github.io/tianqiong-weather/

支持全国 3,195 个市/区县搜索、实时天气、出行建议与当地 5A/4A 景点推荐。

数据源：Open-Meteo（主）/ MET Norway（备）/ BigDataCloud（反向地理编码）；中国城市坐标来自 city-geo 与 public-wheels；5A/4A 景区来自 China Top Attractions（CC BY 4.0）。地球贴图来自 NASA Visible Earth（经 three.js examples 分发）。
