# 数据来源与许可

- `china-cities.js`：中国省/市/区县坐标与层级，整理自 [city-geo](https://github.com/qfz9527/city-geo)（Mulan PSL v2，见 `LICENSE-city-geo.txt`），并用 [public-wheels/china-cities](https://github.com/public-wheels/china-cities)（MIT）的天气城市坐标交叉校正。
- `china-attractions.js`：中国 5A/4A 景区名称、坐标、门票、开放时间与建议游玩时长，来自 [China Top Attractions](https://chinatopattractions.com/china-attractions-dataset/)（CC BY 4.0，2026-08 校验）。
- 天气数据：Open-Meteo（CC BY 4.0）、MET Norway（CC BY 4.0 / NLOD）。
- 地球贴图：NASA Visible Earth（公有领域，经 three.js examples 分发）。
- Three.js r170：MIT。
