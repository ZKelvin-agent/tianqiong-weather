# Earth texture attribution

- Day / clouds / elevation bump / ocean mask: NASA Visible Earth (Blue Marble, cloud composite, GEBCO elevation), public domain, distributed via the `turban/webgl-earth` texture set.
- Night lights: NASA Earth at Night (Black Marble / DMSP composite), public domain, via Wikimedia Commons `The_earth_at_night.jpg`.
- The textures are downscaled to 4096×2048 for web delivery; the night source was 13500×6750.
- Globe still (`globe-still.jpg`) is a render of this project's own Three.js scene.
